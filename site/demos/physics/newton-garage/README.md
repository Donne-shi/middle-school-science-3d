# 牛顿车库 · Newton's Garage

> 七年级科学 · 力与运动 —— 用一辆汽车看懂受力分析与牛顿三大定律。
>
> Grade 7 Science · Forces & Motion — an interactive 3D lesson built around one car.

![牛顿车库预览](preview.png)

## 直接使用

这是一个**无需联网、无需安装、无需构建**的静态网站。

- **最方便**：双击 `index.html`，用 Chrome、Edge、Safari 等支持 WebGL 的浏览器打开。
- **本地服务器（可选）**：

  ```bash
  cd newton-motion-lab
  python3 -m http.server 8000
  ```

  然后访问 <http://127.0.0.1:8000>。
- **发给别人**：直接发送 `newton-garage-standalone.html`，它是把样式、脚本和 Three.js 全部打包进去的单文件版本。

> 首次打开需要加载本地 Three.js（约 0.6 MB），不会请求任何在线资源。建议使用独立显卡/较新的浏览器以获得更流畅的 3D 效果。

## 课程内容

| 章节 | 中文 | English | 3D 演示 |
| --- | --- | --- | --- |
| 01 | 受力分析 | Force analysis | 静止 / 匀速 / 加速三种状态下，汽车受到的重力、支持力、动力和阻力 |
| 02 | 牛顿第一定律 | Newton's First Law | 双车道“有摩擦 vs. 理想无摩擦”对照；起步与急刹车时的乘客惯性（透视剖面） |
| 03 | 牛顿第二定律 | Newton's Second Law | 调节驱动力和质量，实时记录加速度、速度和时间图像 |
| 04 | 牛顿第三定律 | Newton's Third Law | 轮胎—地面力对；1000 kg / 1600 kg 两车碰撞的等大反向力对 |
| 05 | 总结与挑战 | Review & quiz | 三道小结论 + 4 道双语选择题、即时反馈与得分 |

每一章都包含：

- 一段可直接讲解的双语概念说明；
- 一条牛顿定律原文（中英文并列）；
- 一个可亲手操作的 3D 实验；
- 受力图、公式、易错点和“给老师的课堂提示”。

## 操作方式

| 操作 | 作用 |
| --- | --- |
| 拖拽 3D 场景 | 旋转观察汽车与力的方向 |
| 滚轮 / 触控板缩放 | 拉近或拉远镜头 |
| 双击 3D 场景 | 回到该实验的默认镜头 |
| `←` / `→` | 切换上一章 / 下一章 |
| `F` | 进入或退出全屏授课 |
| 左上“中 / EN” | 切换整站语言（包括 3D 标注） |
| 右侧“全屏授课” | 投影时铺满屏幕 |

在手机上，3D 场景上方也提供“EN / 中文”快捷切换按钮。

## 建议课堂流程（40 分钟）

1. **导入 · 5 分钟**：先让学生观察“静止”状态的汽车，问：汽车受到几个力？为什么没有掉下去、也没有飞起来？
2. **受力分析 · 8 分钟**：依次切换“匀速”“加速”，让学生说出合力方向；强调“合力决定运动状态”。
3. **牛顿第一定律 · 8 分钟**：先预测双车道滑行结果，再播放；用乘客急刹车演示解释安全带。
4. **牛顿第二定律 · 10 分钟**：让学生预测“质量变大时加速度如何变化”，再拖动滑块验证，并读 v–t 图。
5. **牛顿第三定律 · 7 分钟**：播放起步和碰撞，追问“这两个力为什么不能抵消？”
6. **课堂挑战 · 2 分钟**：完成 4 道选择题，用最后一道题回到“惯性不是力”。

## 画面与物理说明

- 整车质量统一取 **1,200 kg**；重力取 **11.8 kN**。
- 受力分析、第二定律实验中的“阻力”是空气阻力与滚动阻力的合并简化；第二定律实验固定为 **1.2 kN**。
- 双车道实验中，有摩擦车道受到约 **0.96 kN** 的向后阻力，对应约 **0.8 m/s²** 的减速度；理想车道水平合力为零。
- 碰撞演示采用理想弹性碰撞：两车动量等大反向，碰撞时受力等大反向，较轻的车速度变化更大。真实汽车碰撞会伴随形变和能量损失，课堂中如需强调这一点，可补充说明。
- 3D 视角下的力箭头长度与力的大小成比例，便于比较；位置为教学示意。
