# 中学科学 3D 演示

面向中学科学课堂与自主探索的浏览器交互演示项目。首个主题是太阳系：从太阳和行星图鉴出发，逐步加入太阳系结构及更多可操作的科学演示。

> 项目正在准备公开首版。当前仓库先建立文档与协作规范；演示源码和在线预览会在内容与素材核对完成后加入。

## 首版范围

- 太阳系行星图鉴：太阳、行星及相关天体的交互观察。
- 太阳系结构：用示意动画帮助理解天体分布与空间关系。
- 后续主题持续增加；具体内容以已发布页面为准。

动画用于解释概念。尺寸、距离、速度和时间如经过视觉调整，应在页面中明确标注，不能将示意效果当作等比例模型。

## 运行方式

源码加入仓库后，可使用支持 WebGL2 的新版浏览器打开 `site/index.html`。本地预览也可以运行：

```bash
python3 -m http.server 8000 --directory site
```

然后访问 `http://localhost:8000/`。目前不需要 Node.js 或第三方前端框架。

## 项目结构

首版代码整理完成后，计划使用：

```text
site/                可直接预览的静态页面
solar-system/src/    行星图鉴的源文件
solar-system/assets/ 图鉴使用的贴图
solar-system/build.py 生成图鉴页面的脚本
docs/                素材说明与发布检查
```

页面和目录尚在整理，发布前会同步更新此说明。
