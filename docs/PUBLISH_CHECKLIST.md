# 太阳系演示公开发布检查

此清单针对尚未公开的太阳系演示。四学科网站框架与物理学《牛顿车库》已有独立的公开页面。

- [ ] 确认首批页面和仓库文件清单；仅收录已选定且完成授权核对的内容，其他学科内容后续逐步加入。
- [ ] 完成贴图来源、作者、许可和改动记录；替换或排除来源不明素材。
- [ ] 检查源码与生成页面，移除个人绝对路径、密钥及不应公开的信息。
- [ ] 更新 README 的实际页面、运行与构建说明，移除“准备中”文字。
- [ ] 执行构建，检查生成文件与源文件一致。
- [ ] 在桌面与手机浏览器检查首页、行星切换、太阳系结构、返回导航及 WebGL2 不可用提示。
- [ ] 检查天体名称、教学表述、来源和示意比例说明。
- [ ] 确认 Git 提交只包含选定的公开内容，然后推送到已建立的公开 GitHub 仓库。
- [ ] 如启用 GitHub Pages，检查公开网址实际可打开且页面链接正常。
