# 《原子图鉴》内容依据与教学边界

页面取材于作者提供的 `Documents/gemini/科学模型/`，并在网站副本中调整了表述。以下是本次修改时查阅的资料；原稿的全部数值、公式与互动模拟尚未完成逐项学科审校。

- [Nobel Prize Education：Early Models / A Quantum Theory for Atomic Structure](https://educationalgames.nobelprize.org/educational/physics/quantised_world/structure-1.html)：汤姆孙模型约于 1904 年提出；金箔 α 粒子散射支持卢瑟福的原子核模型。
- [Nobel Prize：Niels Bohr facts](https://www.nobelprize.org/prizes/physics/1922/bohr/facts/)：玻尔 1913 年提出氢原子的量子化能级模型，用跃迁解释固定波长的谱线。
- [Chemistry LibreTexts：Atoms, Elements, and the Nucleus](https://chem.libretexts.org/Bookshelves/General_Chemistry/Chem1_%28Lower%29/04%3A_The_Basics_of_Chemistry/4.01%3A_Atoms_Elements_and_the_Nucleus)：道尔顿曾误将水的分子式写作 HO；页面中的 H₂O 组合采用现代分子式。

页面中的物体尺寸、颜色、电子轨迹、实验粒子数与电子云粒子点均是教学可视化。历史模型应按提出时的认识阅读；现代电子云表示概率分布，不是原子的照片，也不是电子沿固定轨道运动的记录。
