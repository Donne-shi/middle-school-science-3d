# 项目路线图

本项目逐步建设中学科学 3D 演示，覆盖以下四个学科。四学科入口与独立学科首页已建立，内容逐步开放。

| 学科 | 近期方向 | 状态 |
| --- | --- | --- |
| 天文学 | 太阳系行星图鉴、所有行星、太阳系结构 | 入口已建立，演示已接入本地预览；贴图与科学内容待核对后公开 |
| 物理学 | 牛顿车库：受力分析与牛顿三大定律 | 首个 3D 演示已接入 |
| 生物学 | 中学生物 3D 演示 | 待逐步加入 |
| 化学 | 中学化学 3D 演示 | 待逐步加入 |

每个主题在发布前需要检查科学表述、示意比例、交互、移动端体验和素材授权。新增方向可以在 Issue 中讨论。
