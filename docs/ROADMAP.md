# 项目路线图

本项目计划逐步建设中学科学 3D 演示，覆盖以下四个学科。此页只记录方向，不表示已有可用页面；实际进度以仓库中的代码和发布记录为准。

| 学科 | 近期方向 | 状态 |
| --- | --- | --- |
| 天文学 | 太阳系行星图鉴、所有行星、太阳系结构 | 首个制作主题；演示代码仍在整理 |
| 物理学 | 中学物理 3D 演示 | 待逐步加入 |
| 生物学 | 中学生物 3D 演示 | 待逐步加入 |
| 化学 | 中学化学 3D 演示 | 待逐步加入 |

每个主题在发布前需要检查科学表述、示意比例、交互、移动端体验和素材授权。新增方向可以在 Issue 中讨论。
