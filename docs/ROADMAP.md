# 项目路线图

本项目逐步建设中学科学 3D 演示，覆盖以下四个学科。四学科入口与独立学科首页已建立，内容逐步开放。

| 学科 | 近期方向 | 状态 |
| --- | --- | --- |
| 天文学 | 太阳系、宇宙现象、恒星与星空、登月探索 | 11 个单页已开放；月相与日月食模块已加入登月探索 |
| 物理学 | 力与运动、简单机械、电与磁 | 3 个互动演示已接入 |
| 生物学 | 细胞世界、细胞能量与人体系统 | 植物细胞模型、动物细胞模型、细菌图鉴、细胞能量图鉴、人体系统图鉴与病毒图鉴已开放；细胞形态图鉴在本地预览 |
| 化学 | 原子结构 | 原子模型2400年已开放 |

每个主题在发布前需要检查科学表述、示意比例、交互、移动端体验和素材授权。新增方向可以在 Issue 中讨论。
