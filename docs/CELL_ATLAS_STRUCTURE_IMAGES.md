# 细胞图鉴内部结构图：26 张本地教学插画

2026-10-23 为原图鉴的全部 26 个标本制作 AI 教学插画，涵盖细菌、古菌、原生生物、真菌、植物细胞、动物细胞和病毒。它们作为现有图鉴中的**图片视图**展示，不替换图鉴原有的交互模型，也不是显微照片。图中颜色、器官数量、大小和距离为示意，不能用于测量或推断真实比例。

| 首批核对示例 | 重点结构 | 核对依据 |
| --- | --- | --- |
| 大肠杆菌 | 细胞包膜、拟核、70S 核糖体、周生鞭毛 | [OpenStax Microbiology](https://openstax.org/books/microbiology/pages/3-3-unique-characteristics-of-prokaryotic-cells)、[NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/NBK8477/)、[BioNumbers](https://bionumbers.hms.harvard.edu/bionumber.aspx?id=100100) |
| 叶肉细胞 | 细胞壁、叶绿体、中央液泡、细胞核 | [OpenStax Concepts of Biology](https://openstax.org/books/concepts-biology/pages/3-3-eukaryotic-cells) |
| 神经元 | 树突、细胞核、尼氏体（粗面内质网）、轴突 | [NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/NBK28209/) |
| T4 噬菌体 | 蛋白质衣壳、双链 DNA、尾鞘、基板、长尾纤维 | [RCSB PDB 1S2E](https://www.rcsb.org/structure/1S2E)、[RCSB PDB 1K28](https://www.rcsb.org/structure/1K28) |

T4 噬菌体是病毒颗粒，不是细胞；因此该图不标注细胞质、细胞核或细胞器。大肠杆菌示意图的长鞭毛分布在细胞周围。叶肉细胞中央液泡占据主要体积，叶绿体位于周边。神经元采用多极神经元的示意形态，并非所有神经元的通用形状。

数字标注和中英文名称由网页代码叠加，图像本身不含文字。这样后续可单独修订术语和描述。图片仍需由学科教师审阅后才能作为正式教材配图；尤其要检查 AI 图像中的细节、简化和可能的伪结构。未完成审阅前不纳入公开站点。

本地文件放在 `local_assets/cell-atlas/`，该目录与导入后的 `preview/` 都由 Git 忽略。使用 `python3 scripts/import_cell_atlas.py --source /path/to/细胞图鉴-单文件版.html` 重建预览。若 26 张图片不齐，脚本不会添加图片视图。

## 全部标本与核对点

| 类别 | 标本 | 主要核对点 |
| --- | --- | --- |
| 细菌、蓝细菌 | 大肠杆菌、金黄色葡萄球菌、念珠藻、生殖支原体 | 原核拟核、包膜差异；念珠藻的异形胞；支原体无细胞壁 |
| 古菌 | 甲烷古菌、嗜盐古菌 | 无肽聚糖壁；S 层、细胞膜、气囊或紫膜斑块 |
| 原生生物 | 变形虫、草履虫、衣藻、圆筛藻 | 伪足、口沟与双核、杯状叶绿体、硅质荚壳 |
| 真菌 | 酿酒酵母、青霉 | 出芽、菌丝隔膜与外生分生孢子 |
| 植物细胞 | 叶肉细胞、洋葱鳞茎表皮细胞、根毛细胞 | 大液泡；洋葱鳞茎表皮通常无绿色叶绿体；根毛是单细胞延伸 |
| 动物细胞 | 成熟人红细胞、神经元、骨骼肌细胞、人精子、白色脂肪细胞、中性粒细胞、成熟人卵细胞 | 红细胞无核；多核肌纤维；单房脂滴；中性粒细胞的分叶核；MII 卵细胞没有完整核膜 |
| 病毒 | T4 噬菌体、烟草花叶病毒、腺病毒、新型冠状病毒 | 病毒不是细胞；TMV 螺旋衣壳、腺病毒无包膜、冠状病毒有脂质包膜 |

每张插画的标本名称、科学说明、结构名称、中英双语解释及核对来源集中在 `web/biology/cell-atlas/structure-gallery.js` 和 `structure-gallery-data.js`，便于逐张修订。图像的生成约束是：深色显微世界风格、清晰的单标本剖面、无内嵌文字、仅绘制该类群确有的关键结构，不混入其他类群的细胞器；最终用网页叠加数字热点。生成图是示意画，微观比例、数量、颜色和部分细节仍需学科教师逐张复核。

**阶段说明：** 图片中人卵细胞选择成熟的减数第二次分裂中期（MII），因此显示纺锤体与第一极体，没有完整的核膜或生发泡。原单文件图鉴的 3D 说明把生发泡阶段和 MII 阶段混在一起；该 3D 内容尚需单独校订，不能直接把它作为 MII 准确模型。

生成图片存放在 Git 忽略的 `local_assets/cell-atlas/`，预览导入的副本也被忽略。在未完成人工科学审阅和原图鉴显微照片授权核查前，图片与演示副本不会进入公开 GitHub 页面。
