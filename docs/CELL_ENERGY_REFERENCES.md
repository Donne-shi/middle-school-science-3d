# 细胞能量图鉴：内容依据与教学边界

公开版《细胞能量图鉴》由作者提供的单文件改编。两张 AI 生成图片是结构示意，不是显微照片；颜色、形状、膜的厚度和细胞器间比例均经过视觉处理。图片文字使用页面 HTML 呈现，可在中文与英文之间切换。

## 核对过的关键表述

- [OpenStax Biology 2e：光合作用概述](https://openstax.org/books/biology-2e/pages/8-1-overview-of-photosynthesis)与[光反应](https://openstax.org/books/biology-2e/pages/8-2-the-light-dependent-reactions-of-photosynthesis)：叶绿体利用光能；类囊体膜参与光反应，释放的氧气来自水。
- [OpenStax Biology 2e：氧化磷酸化](https://openstax.org/books/biology-2e/pages/7-4-oxidative-phosphorylation)：有氧呼吸的电子传递链位于线粒体内膜，氧气是最终电子受体；糖酵解先在细胞质中进行。
- [菠菜叶绿体 ATP 合酶 c 环结构研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3971453/)：其一周旋转涉及约 14 个质子并合成 3 个 ATP；同一研究也比较了哺乳动物线粒体的较小 c 环。原稿把线粒体和叶绿体都写成“每 3 个 H⁺ 转一圈、产 3 个 ATP”，不成立。不同物种与实验条件会影响耦联比例，因此公开版不把光反应 ATP 产量写成固定输出。

全篇还有较多高中及大学层级的细节和估算值，适合在教师引导下选读。演示中的分子位置、反应路径和运动速度用于帮助理解过程，并非直接观测或精确模拟。
